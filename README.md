# АвтоВесы (weigh_station)

Десктоп-приложение (WPF, .NET 8, Windows) для автоматизированной автомобильной весовой:
взвешивание, распознавание госномера, управление светофором и шлагбаумом, журнал, справочники, отчёты.

Как устроен код и почему — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Экраны

Левая панель навигации (видны только разделы, доступные вашей роли), внизу строка состояния: устройства, пользователь, часы, «Сменить пароль» и «Выйти».

| Раздел | Что делает |
|---|---|
| Взвешивание | вес в реальном времени, номер с камеры или вручную, форма рейса с подсказками из справочников, контроль допустимой массы, кнопка «Зафиксировать» (F5), ручное управление шлагбаумом |
| Журнал | поиск по периоду, номеру, контрагенту, статусу; правка данных рейса с историей; отмена записи; талон на печать; экспорт в CSV (Excel) |
| Справочники | транспорт (тара, допустимая масса), контрагенты, грузы, водители; после взвешивания пополняются сами |
| Отчёты | по контрагентам, грузам, транспорту, дням; итоги; экспорт в CSV |
| Устройства | состояние оборудования, сигналы датчиков в реальном времени, ручное управление, симуляция отказов, параметры подключения |
| Импорт | перенос справочников и истории взвешиваний из Excel (.xlsx, .xls) и CSV: подбор колонок, предпросмотр с проблемами, загрузка одной транзакцией ([инструкция](docs/MIGRATION.md)) |
| Пользователи | учётные записи, роли, временные пароли, разблокировка, журнал безопасности |
| Настройки | правила стабильности и фиксации, автофиксация, резервная копия БД |

## Доступ

При первом запуске программа просит создать администратора — паролей «по умолчанию» нет. Дальше вход по логину и паролю.

| Роль | Что может |
|---|---|
| Оператор | взвешивание, ручное управление шлагбаумом, просмотр журнала, печать талона |
| Менеджер | всё, что оператор, плюс правка и отмена записей, справочники, отчёты, экспорт, просмотр устройств |
| Администратор | всё: пользователи, настройки, устройства, импорт |

Пароли хранятся только в виде PBKDF2-хэша, после 5 неверных попыток запись блокируется на 5 минут, выданный администратором пароль временный (его нужно сменить при входе), последнего администратора нельзя отключить или понизить. Имя вошедшего пользователя записывается в историю каждого взвешивания и правки; события безопасности видны на странице «Пользователи».

## Структура

| Проект | Назначение |
|---|---|
| `src/WeighStation.Core` | правила без зависимостей от оборудования и UI: цикл (`WeighingSession`), стабильность веса, номера, отчёты, интерфейсы |
| `src/WeighStation.Infrastructure` | SQLite, настройки в JSON, симулятор оборудования |
| `src/WeighStation.Presentation` | ViewModel-и и интерфейсы сервисов UI (без WPF, тестируются на любой ОС) |
| `src/WeighStation.App` | WPF: окна, стили, диалоги, печать, точка входа (только Windows) |
| `tests/WeighStation.Core.Tests` | xUnit |

## Сборка и запуск

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
dotnet test tests/WeighStation.Core.Tests    # любая ОС
dotnet build                                 # всё решение; WPF-часть только на Windows
dotnet run --project src/WeighStation.App    # только Windows
```

Данные: `%LOCALAPPDATA%\WeighStation\` (`weighings.db`, `settings.json`, `error.log`).
Приложение стартует с симулятором: грузовики заезжают по кругу. На экране «Устройства» можно отключить весы или камеры и посмотреть, как приложение реагирует.

## Подключение реального оборудования

Нужно реализовать интерфейсы из `WeighStation.Core.Abstractions` и заменить `SimulatedHardware` в `App.xaml.cs`:

- `IScale` — терминал/SIWAREX (Modbus TCP / S7 / RS-485), событие на каждое показание.
- `IPlatformIo` — ПЛК S7: датчики платформы на вход, светофор и шлагбаум на выход.
- `IPlateRecognizer` — события ANPR-камеры.
- `IDeviceMonitor` — состояние связи с каждым устройством.

`ISimulationControl` передавайте `null`: панель симуляции скроется сама.

## Что пока не сделано

- Видеопотоки камер (в окне заглушки) и снимки в журнале.
- Драйверы реального оборудования (параметры подключения уже сохраняются).
- Автоблокировка по бездействию и ограничение попыток входа в целом по программе (сейчас блокируется конкретная учётная запись).
- Экспорт справочников (импорт есть).
- Аппаратная блокировка шлагбаума по фотобарьеру должна быть в самом ПЛК/шлагбауме, не в программе.
