# АвтоВесы (weigh_station)

Десктоп-приложение (WPF, .NET 8, Windows) для автоматизированной автомобильной весовой:
взвешивание, распознавание госномера, управление светофором и шлагбаумом.

## Структура

| Проект | Назначение |
|---|---|
| `src/WeighStation.Core` | Предметная логика без зависимостей от оборудования и UI: цикл взвешивания (`WeighingSession`), определение стабильности веса (`StabilityTracker`), интерфейсы устройств и хранилища |
| `src/WeighStation.Infrastructure` | SQLite-журнал (`SqliteWeighingRepository`, он же справочник тары) и симулятор оборудования (`SimulatedHardware`) |
| `src/WeighStation.App` | WPF-приложение (MVVM, CommunityToolkit.Mvvm). Собирается только на Windows |
| `tests/WeighStation.Core.Tests` | xUnit: логика цикла, стабильность веса, SQLite, прогон цикла на симуляторе |

## Цикл взвешивания

```
Idle ──въезд──▶ Entering ──ТС целиком на платформе──▶ Weighing ──вес стабилен + номер известен──▶ ReadyToCapture
  ▲                                    (светофор красный)                                              │ Capture (F5 / авто)
  └──────────────── ТС покинуло платформу и выезд ◀── Exiting (шлагбаум открыт) ◀──────────────────────┘
```

- Светофор: зелёный в `Idle`, красный с момента, когда ТС целиком на платформе, до конца выезда.
- Шлагбаум открывается только после успешной записи веса и закрывается, когда платформа и датчик выезда свободны.
  Очередь на въезде не держит шлагбаум открытым.
- Фиксация веса требует: ТС целиком на платформе, вес ≥ `MinWeightKg`, стабильность по собственному окну
  (`StabilityTracker`) и по флагу терминала, номер (распознан с уверенностью ≥ `MinPlateConfidence` или введён вручную).
- Если сохранить в БД не удалось, шлагбаум остаётся закрытым, цикл остаётся в `ReadyToCapture` — можно повторить.
- Логика цикла живёт в ядре, а не в UI, чтобы её можно было тестировать и позже переносить пороговые/аварийные части в ПЛК.

## Запуск

Приложение стартует с симулятором (`SimulatedHardware`): грузовики заезжают по кругу, вес растёт и стабилизируется.

```bash
dotnet test tests/WeighStation.Core.Tests   # любая ОС (решение целиком на Linux не соберётся: нет WindowsDesktop SDK)
dotnet run --project src/WeighStation.App   # только Windows
```

База: `%LOCALAPPDATA%\WeighStation\weighings.db`.

## Подключение реального оборудования

Нужно реализовать три интерфейса из `WeighStation.Core.Abstractions` и заменить `SimulatedHardware` в `App.xaml.cs`:

- `IScale` — терминал/SIWAREX (Modbus TCP / S7 / RS-485), событие на каждое показание.
- `IPlatformIo` — ПЛК S7: датчики платформы на вход, светофор и шлагбаум на выход.
- `IPlateRecognizer` — события ANPR-камеры (ISAPI/HTTP/SDK производителя).

## Что пока не сделано

- Видеопотоки камер (в окне — заглушки), отдельные окна журнала/справочников/настроек.
- Ограничение допустимой массы ТС, проверка возврата весов на ноль между машинами.
- Связь с ПЛК на уровне безопасности: аппаратная блокировка шлагбаума по фотобарьеру должна быть в самом ПЛК/шлагбауме.
