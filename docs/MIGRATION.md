# Перенос данных из другой системы

Страница **«Импорт»** (только администратор) загружает справочники и историю взвешиваний из Excel или CSV.

## Порядок

1. Сделайте резервную копию: **Настройки → Создать резервную копию**.
2. Загружайте в таком порядке: **контрагенты → грузы → водители → транспорт → журнал**. Транспорт и журнал ссылаются на названия, поэтому справочники удобнее иметь заранее (но это не обязательно).
3. Выберите раздел, нажмите **«Скачать шаблон»**, чтобы увидеть, какие колонки понимает программа, или сразу **«Выбрать файл…»**.
4. Проверьте **соответствие колонок** — программа подбирает их по названиям (`Госномер`, `Гос. номер ТС`, `Номер` — всё подойдёт). Неверно угаданное исправьте вручную.
5. Посмотрите **предпросмотр**: «Добавить», «Обновить», «Пропуск», «Ошибка». У каждой строки с проблемой есть пояснение. Кнопка **«Сохранить строки с проблемами…»** выгружает их в файл вместе с исходными ячейками — исправьте в Excel и загрузите снова.
6. Нажмите **«Импортировать»**. Запись идёт одной транзакцией: при сбое не будет загружено ничего.

## Файлы

* Форматы: `.xlsx`, `.xls`, `.csv` (разделитель `;` `,` табуляция — определяется сам; кодировки UTF-8, UTF-16 и Windows-1251).
* Первая строка — заголовки. Читается первый лист, где есть данные. Пустые строки пропускаются.
* Номера строк в сообщениях совпадают с номерами строк в Excel.

## Что понимает программа

| Что | Как можно писать |
|---|---|
| Госномер | `А123ВС197`, `а 123 вс 197`, `A123BC197` (латиница заменяется кириллицей) |
| Дата | `28.10.2026 14:32`, `28.10.2026`, `2026-10-28 14:32`, настоящая дата Excel; время можно в отдельной колонке |
| Масса | `42780`, `42 780`, `42 780 кг`, `42,78` (тонны) — единицу («Килограммы»/«Тонны») выбирает пользователь |
| Операция | `Брутто`, `загруженный`, `Тара`, `порожний`; если колонки нет — по тому, какая масса указана |
| Нетто | считается как брутто − тара; если в файле другое число, берётся вычисленное и выводится предупреждение; если нет тары, но есть брутто и нетто — тара вычисляется |

## Правила и защита

* **Дубли.** Повторы внутри файла и записи, которые уже есть, пропускаются. Один и тот же файл можно загрузить второй раз — ничего не добавится.
* **Существующие записи.** По умолчанию не меняются. Галочка «Дополнять уже существующие записи» заполняет только те поля, которые есть в файле; пустая ячейка ничего не стирает.
* **История.** У каждой загруженной записи в истории будет строка «Импортировано из файла …» с именем администратора.
* **Подозрительные значения** помечаются предупреждением, но не блокируют: масса меньше 500 кг (вероятно, тонны), дата далеко в будущем (вероятно, перепутаны день и месяц), ИНН не из 10/12 цифр, тара не меньше допустимой массы.
* Ограничения: файл до 100 МБ и до 200 000 строк — крупнее разбейте на части.
* Загрузка записана в журнал безопасности.
